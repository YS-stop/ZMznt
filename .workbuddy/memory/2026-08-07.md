## 排查「启动后几十秒自动终止」（段错误）

**根因**：PySide6 与 torch 的 DLL 加载顺序冲突。对比实验实锤：先 `from PySide6...` 再 `import torch` → `OSError WinError 1114 DLL 初始化例程失败 (c10.dll)`；先 torch 再 PySide6 → 正常。完整 App 中表现为 access violation 段错误（37~76 秒后进程无声消失，EXIT_CODE=139）。
**修复**：`src/main.py` 文件顶部、`from PySide6...` 之前插入 `_preload_asr_native_deps()`（import torch/funasr/modelscope/sounddevice/soundfile，失败静默降级）。修复后长跑 5 分钟+ 稳定。
**注意**：这只是 import 顺序问题，与线程无关（一开始误判为子线程加载 C 扩展问题，在 ui_bridge 里做的主线程预加载也崩，因为 PySide6 在 main.py 顶部更早 import）。
**附带发现**：PySide6 6.6.3.1 的 shiboken6 是按 NumPy 1.x ABI 编译的，在 numpy 2.4.6 下会打印兼容警告，但不影响运行，可忽略（如以后要消警告可升级 PySide6 到 6.7+）。

## 浏览器关闭能力增强迭代（第二轮）

`src/tools/browser_tools.py` 大改，工具总数 16→17：
- **open_browser 默认带调试端口启动**：`_find_chromium_exe()`（注册表 UserChoice 默认浏览器 → Chrome/Edge 常见路径兜底，本机 Chrome 在 `E:\Guge\Chrome\Application\chrome.exe`）+ `_open_url_with_cdp()` subprocess 带 `--remote-debugging-port=9222` 启动并轮询验证 CDP。返回三元组 (cdp_ok, url_opened, note)——url_opened=True 时绝不能再用 webbrowser 重复打开（否则旧实例在跑时会开两个相同标签，已踩过并修复）
- **close_browser_tab 加 mode 参数**：site(默认,批量)/others(关其他标签)/duplicates(同站点主域只留一个)/all(整浏览器)；target=「全部」自动转 all 兼容旧用法
- **duplicates 用站点主域分组**（`_site_key_of` 取域名末两段，.com.cn 类取末三段），否则 cart.taobao.com 与 taobao.com 会被当成不同站点
- **无 CDP 降级增强**：`_close_matching_tabs_via_window` 循环「读标题→匹配→Ctrl+W→标题变了继续」，实现无调试端口时的连续批量关
- **新工具 restore_browser_tab**：置前台浏览器 + 循环 Ctrl+Shift+T，count 1~10
- **关闭反馈可感知**：CDP 模式报告「关了 N 个，还剩 M 个标签」
- `_cdp_close_others` 当前页识别：GetForegroundWindow 标题剥离浏览器后缀（" - Google Chrome" 等）后与 CDP 标签标题精确→模糊比对，定位不到则拒绝执行保安全
- 测试：`tests/test_browser_close_enhanced.py`（mock CDP 逻辑 + 路由 + 降级，RUN_LIVE=1 真机）；另用独立 `--user-data-dir` 隔离 Chrome 实例做了 CDP 端到端验证（列出/精确关后台标签通过），不影响用户主浏览器
- 系统提示词 `agent_service.py` 3.5 重写 + 新增 3.55 restore_browser_tab；现状总结 md 已同步更新

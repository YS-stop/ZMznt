## 三项需求实现（关闭标签页 / 监听时长 / 任务打断确认）

**A. close_browser_tab 工具**（`src/tools/browser_tools.py`）：
- 三级策略：① CDP HTTP 端点精确关标签（`/json/close/{id}`，无需 websocket，端口 9222/9223）② 兜底：ctypes 枚举窗口标题匹配 → Alt 解锁前台 → 模拟 Ctrl+W ③ 无匹配时列出当前浏览器窗口帮用户定位
- target=「全部」→ 给所有浏览器窗口发 WM_CLOSE 优雅关闭（不 taskkill）
- 关键词匹配：站点中文名 + 域名双匹配（抖音→"抖音"/"douyin"）
- 已注册进 `tools/__init__.py`（工具总数 13），`agent_service.py` 系统提示词加了 3.5 条目并去掉"6 个工具"硬编码
- 局限：浏览器未开 `--remote-debugging-port` 时只能关激活标签（窗口标题匹配机制决定）

**B. VAD 监听时长**（`wake_word_service.py`）：END_SILENCE_FRAMES 24→40（静音判停 0.72s→1.2s），MAX_SEGMENT_SEC 12→15。

**C. 任务打断确认状态机**（`ui_bridge_service.py`）：
- `submit_text` 变路由器：等答案中→走回答处理；忙碌→缓冲新指令+气泡/TTS 询问「要中止当前任务执行新指令吗」；空闲→`_start_task`
- 代际守卫（`_task_generation`）：被取代的旧任务结果直接丢弃不弹气泡不播报
- 确认/否定/超时（12s 默认保留当前）三分支；回答分类器 `_classify_switch_answer`（强确认短语→"不/别"开头否定→否定词→确认词→unclear 保守不换）
- TTS 询问播完自动开 10 秒免唤醒词等答案窗口（`WakeWordService.expect_command`）
- 新任务启动时 `tts_stop_playback()` 掐断上一任务播报（`tts_service.stop_playback` 新增）
- 唤醒监听暂停策略调整：只在 TTS 播报和手动按住说话时暂停；Agent 思考期间保持监听（用户才能语音打断）
